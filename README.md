# 제주 역사문화 탐방기

제주특별자치도 「제주역사문화」 일반정보·위치정보(공공데이터포털 API)를 장소 120곳으로 합쳐, 테마 코스로 둘러보고 나만의 답사 코스를 만드는 사이트입니다.

## 화면 구성

HTML 페이지는 2개(`index.html`, `search.html`)이고, 화면은 **5종**입니다. 상단 메뉴는 `홈 · 테마 코스 · 내 답사수첩 · 자료 조회`입니다.

| # | 화면 | 주소 | 파일 |
|---|------|------|------|
| 1 | 홈 | `/#/` | `public/index.html` |
| 2 | 테마 코스 (7개) | `/#/course/{sea·oreum·eco·water·faith·fort·life}` | `public/index.html` |
| 3 | 내 답사수첩 | `/#/mine` | `public/index.html` |
| 4 | 장소 상세 (팝업창) | 별도 주소 없음 | `public/index.html` |
| 5 | 자료 조회 | `/search.html` | `public/search.html` |

`index.html`은 주소의 `#` 뒤 경로로 1~4번 화면을 바꿔 보여 주는 한 페이지입니다.

### 1. 홈 `/#/`
- **첫 화면**: 제목, 소개, 숫자 요약(장소 수 · 코스 수 · 제주시/서귀포시 수)
- **오늘의 장소**: 날짜마다 바뀌는 장소 1곳의 요약, 이야기 읽기, 찜하기, 소속 코스로 이동
- **테마 코스**: 코스 7개의 카드. 곳 수, 직선거리, 시작과 끝 장소를 보여 주고 클릭하면 해당 코스로 이동
- **한눈에 보기**: 120곳 전체를 테마 색 핀으로 찍은 지도. 범례를 눌러 테마별로 켜고 끔
- **두 고장의 분포**: 제주시와 서귀포시의 장소 수 비교 막대

### 2. 테마 코스 `/#/course/{테마}`
7개 코스가 같은 틀을 씁니다.

| 코스 | 키 | 곳 수 |
|------|----|------|
| 바다와 포구 | `sea` | 32 |
| 오름과 봉우리 | `oreum` | 18 |
| 숲·습지·철새 | `eco` | 10 |
| 물과 하천 | `water` | 15 |
| 신당과 절터 | `faith` | 18 |
| 성곽과 근대의 흔적 | `fort` | 18 |
| 고분과 삶의 터 | `life` | 9 |

- **머리말**: 코스 소개, 곳 수, 직선거리 합계, 제주시/서귀포시 수, 출발지 → 도착지
- **장소 카드 목록**: 번호, 장소명, 지역, 이전 장소까지의 거리, 초록 요약. 버튼은 이야기 읽기 · 지도에서 보기 · 수첩에 담기
- **지도**: 번호 핀과 점선 경로. 핀을 누르면 설명 팝업이 열리고 해당 카드가 강조됨
- **이전/다음 코스** 링크

### 3. 내 답사수첩 `/#/mine`
- **담은 장소 카드**: 담은 순서대로 번호가 붙음. ▲▼로 순서 변경, ✕로 빼기
- **지도**: 담은 순서대로 이은 주황색 경로
- **요약**: 곳 수와 직선거리 합계
- **도구**: 코스를 글로 복사, 전체 비우기
- **빈 상태**: 담은 장소가 없으면 안내와 코스 둘러보기 버튼

### 4. 장소 상세 (팝업창)
홈, 코스, 수첩, 지도 팝업의 "이야기 읽기"로 열립니다. 테마 칩, 장소명, 주소, 수첩 담기, 원문 링크, 자료 정보(제목 · 부제 · 저작자 · 발행자 · 발행일 · 분류 · 좌표), 초록, 내용, 참고문헌을 보여 줍니다. `Esc`나 바깥 클릭으로 닫습니다.

### 5. 자료 조회 `/search.html`
데이터를 표로 찾아보는 화면입니다.
- **필터**: 검색어(장소명 · 제목 · 주소 · 내용), 분류, 디렉토리, 지역, 초기화
- **목록 표**: 번호 · 장소명 · 분류 · 디렉토리 · 지역 · 주소. 열 제목을 눌러 정렬하고, 찜한 장소는 ★ 표시
- **지도**: 필터 결과의 핀만 표시됨(찜한 핀은 항상 표시). 핀 설명 팝업에서 찜 가능
- **답사 코스 카드**: 찜한 순서, 구간 거리, 순서 변경, 전체 삭제
- **상세 카드**: 선택한 장소의 정보, 초록, 내용, 참고문헌

### 공통 동작
- **찜 목록 공유**: 탐방기와 자료 조회가 같은 저장소(`jejuFavs`)를 써서, 한쪽에서 담으면 다른 쪽에도 반영됩니다. 이 브라우저에만 저장됩니다.
- **불러오는 중**: 데이터를 받는 동안 회전 표시와 "데이터를 불러오는 중…"이 나옵니다.
- **연습 모드**: 데이터 API 호출이 실패하면(키 없음·잘못된 키·연결 실패 등) 1단계 파일 데이터(루트의 CSV 2개, 2022-12-09 기준)로 화면을 보여 주고, 상단에 노란 "연습 모드" 배너와 실패 사유를 표시합니다. 배너의 "API 다시 연결"을 누르면 화면을 유지한 채 재시도하고, 성공하면 API 데이터로 바뀌며 배너가 사라집니다. 파일 데이터까지 못 읽으면 오류 화면과 "다시 시도" 버튼이 나옵니다.
- **지도**: 배경 지도는 인터넷에서 불러오므로 연결이 없으면 안내 문구가 대신 나옵니다.

## 폴더 구성

```
server.js       정적 파일 제공 + 데이터포털 API 중계 (서비스키는 환경변수에서만 읽음)
themes.js       장소명 → 테마 코스 분류
public/         index.html, search.html
legacy/         API 도입 전 파일 방식 HTML (참고용)
*.csv           1단계 파일 데이터 (연습 모드에서 사용 — 지우지 마세요)
.env.example    필요한 환경변수 이름
```

## 데이터 API

브라우저는 서버의 `/api`만 호출합니다.

| 주소 | 내용 |
|------|------|
| `/api/places` | 일반정보 + 위치정보를 `데이터 고유번호`로 합친 장소 목록 (화면이 사용) |
| `/api/practice` | 연습 모드용. 루트의 CSV(1단계 파일 데이터)를 같은 형태로 합친 장소 목록 |
| `/api/info` | 일반정보 원본 (`page`, `perPage`) |
| `/api/location` | 위치정보 원본 (`page`, `perPage`) |
| `/api/health` | 환경변수 설정 여부(true/false만 표시) |

## 실행

1. `.env.example`을 `.env`(또는 `.env.local`)로 복사하고 발급받은 키를 넣습니다.
   - `JEJU_CULTURE_INFO_KEY`: 제주역사문화 일반정보(15109587)
   - `JEJU_CULTURE_LOCATION_KEY`: 제주역사문화 위치정보(15109570)
2. 실행합니다.
   ```bash
   npm start
   ```
3. `http://localhost:3000`에 접속합니다. (`PORT` 환경변수로 포트 변경 가능)
